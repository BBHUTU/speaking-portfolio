01 · 计时与模式

倒计时归零，不是结束

讲嗨了不被机器打断，讲没词了自己按停 —— 尊重真实的表达节奏

1

双模式计时

即兴开讲 60 秒 / 深度研究 180 秒

  • 两种模式：即兴开讲对应短准备，深度研究对应长准备，时长分开记忆
  • 超时不打断：倒计时归零只响铃，自动切换正计时（橙色脉冲环），讲到自己满意为止
  • 完成语义：只有点「我说完了」才算走完一轮，中途放弃不计入历史
  • 环形进度：剩余时间一目了然，超时后数字变号继续走
每天在用
2

只讲一遍的录音链路

一个真实抱怨逼出来的架构修正

  • 原来的问题：计时里讲的第一遍没录上，进复盘又要求「再说一遍」—— 一轮练习讲两遍
  • 修正：录音从「开讲」那一刻启动，识别与留底音频并行，复盘面板直接复用
  • 假死看门狗：识别服务被墙时「不报错也不出字」，看门狗自动检测并停止识别 —— 「你说的话一点没丢，音频已留底」
  • 环境识别：微信 / 飞书等 App 内置浏览器整体禁麦克风，直接告诉用户「换 Safari 打开」，而不是让人去翻系统设置

02 · 诊断报告

每一条结论，都带着你说的原话

主题 / 优点 / 缺点 / 口头禅 / 综合评分五个板块，不写空话，判断给证据

3

五板块诊断

像教练点评，不像机器报数

  • 优点带证据：「收尾有落点：最后一句收在『最后记得收尾…』」—— 引原话，不给套话
  • 缺点可定位：「句子太长（3 处超 50 字）：最长一句 91 字，一口气讲完听众接不住」
  • 主题诚实标注：工具不认语义，核心词按词频算，页面上原样说明，不假装读懂了
  • 口头禅洞察：口头禅是 0 但长停顿 12 次 = 卡壳换了个形式，两个指标放在一起解读

03 · 评分与数据

机械指标交给机器，进步看得见

口头禅、停顿、语速、重复、时间控制 —— 十分制，每一分都能复算

4

十分制五维评分

口头禅 3 · 长停顿 1 · 语速 1 · 重复 3 · 时间控制 2

  • 重复三层检测：紧邻重复「X，X」、重复分句、高频短语 —— 还要过滤「的人生」这类虚词误报
  • 时间控制算净账：准点且讲满八成 +2，超时按比例扣，鼓励把内容压缩进时限
  • 指标会自曝局限：语速受转写完整度影响，页面标注「仅供参考」，不装精确
  • 评分构成表：每行是维度 / 实测值 / 得分-满分，绿橙红三色，低分知道低在哪
已上线
5

历史与跨设备同步

本地为主，云只是合并通道

  • 选型实测：逐一试了 7 家免费云服务，结论「curl 通了不算数，CORS 才是判官」，最后只有 JSONBin 能用
  • 私有仓库：同步码对应私密 bin，拿到码没有密钥也读不出内容
  • 本地永不丢：localStorage 是主存储，云挂了 / 额度满了，本地记录一条不少
  • 合并规则：按记录 id 求并集，同 id 取更新的，防止云端截断版覆盖本地全文

04 · 洗稿

不假装能做语义改写

545 字无标点的口播原稿，机器负责断句和去重，一个词都不替你换

6

结构重排稿

只动标点和分段，用词一字不改

  • 停顿变标点：停顿 ≥8 秒分段、≥3 秒句号、≥1.2 秒逗号 —— 按你实际的呼吸重排
  • 半截话识别：停顿前以「的 / 一种 / 是 / 因为…」结尾，说明话没说完，用逗号不硬断
  • 去重不动词：先删口头禅再删重复，之后只调标点 —— 重构稿必须通过「子序列校验」（逐字按序比对原稿）才能展示
  • 边界写在脸上：纯离线网页读不懂语义，换词、金句、重组论证 —— 做不到就不承诺
  • 量化对比：重排后自动给出字数 / 句数 / 平均句长 / 最长句的变化表

E2E

Playwright 覆盖全流程：计时归零转正计时、诊断五板块顺序、重构稿子序列校验、麦克风授权录音、控制台零报错。页面抛错即使功能全对也算失败。

权限

麦克风在 iframe 里必挂

发布平台把页面套进跨域 iframe，而 iframe 没有 allow="microphone" —— 录音必然被拒且无解。最终方案：上传公网直链顶层打开，iPhone Safari 实测录音正常。

选型

七家免费云逐一实测

免注册云全部死于 CORS 或容量：有的 Cloudflare 403，有的写接口不返回跨域头，有的单条超 1.5KB 就 500。结论沉淀成选型方法：浏览器里测，CORS 是判官。
